Quick answer

For voice cloning, start with models that explicitly support cloning or expressive speaker control, then test pronunciation, consent requirements and license constraints before production use.

Recommended starting points

#1

F5-TTS v1 Base

Speech Research (SWivid) · catalogue quality 9.5/10 · catalogue speed 9.2/10

Catalogue summary: The official F5TTS_v1_Base checkpoint released in March 2025. The preserved route ID reflects the 1.1 package line, not a separate F5-TTS-v1.1 model checkpoint.

F5-TTS

MaskGCT

Amphion Team · catalogue quality 9.4/10 · catalogue speed 9/10

Catalogue summary: Fully non-autoregressive TTS — no text-phone alignment needed. Achieves human parity on naturalness and similarity metrics. Incredibly fast inference.

#4

ZONOS2

Zyphra · catalogue quality 9.6/10 · catalogue speed 8.5/10

Catalogue summary: Zyphra's second-generation open-weight multilingual TTS MoE with high-fidelity voice cloning, streaming server output, offline Python inference and emotion controls. The canonical HF checkpoint ships a 15.3GB model file and the official runtime targets local Linux CUDA through Mini-SGLang, with a separate ggml path noted for CPU and cross-platform support.

#5

Breeze TTS 2

BreezeBlue · catalogue quality 9.6/10 · catalogue speed 8.4/10

Catalogue summary: BreezeBlue's open-weight 3B speech generation model for real-time bilingual English and Chinese TTS. It supports reference-audio voice cloning, text-only voice design, voice direction, inline vocal events and a local PyTorch streaming API, with a 12 GB CUDA GPU floor for eager inference.

cloningstreamingrealtimeemotioncontrollable
#6

Audio8 TTS Preview 0.6B

Audio8 · catalogue quality 9.3/10 · catalogue speed 8.9/10

Catalogue summary: Compact multilingual text-to-speech model with zero-shot voice cloning. The release ships a 601M parameter PyTorch checkpoint, bundled 44.1 kHz codec and an official ONNX INT4 package for CPU inference with streaming PCM, voice registration and about 1 GiB loaded memory on an Apple M2 test machine.

Zonos v0.1

Zyphra · catalogue quality 9.5/10 · catalogue speed 8.5/10

Catalogue summary: 1.6B open-weight TTS with ultra-realistic zero-shot cloning from 5-30 s audio. Fine-grained controls: speaking rate, pitch, emotion (happy/sad/angry/fear). Streaming with ~200 ms first-token latency.
