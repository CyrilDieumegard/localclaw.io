For writers, educators & builders

Give readers a result they can check.

Link directly to the tool or model page you used. For memory estimates, include the calculation link, method version and inputs. For model compatibility, cite the individual model page and its original sources, and distinguish a published hardware floor from a measured result.

LocalClaw. Local LLM Memory Calculator, method v1.0 (November 2, 2026). https://localclaw.io/local-llm-memory-calculator. Planning estimate, with input settings supplied in the result link.

Dataset scope matters

The historical GitHub release retains its published CC BY 4.0 licence. It includes hosted-model references and estimates that must be checked before current use. New LocalClaw compilations and compatibility analyses have separate data reuse terms; the historical licence does not extend to them. Model weights and third-party software keep their own licences.

To report a calculator issue, open an issue with the result link and expected behaviour. For dataset reuse questions, contact LocalClaw.
