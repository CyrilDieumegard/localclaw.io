# Model directory logo assets

The SVG files in this folder are copied from `@lobehub/icons-static-svg` 1.94.0,
the MIT-licensed static build of [Lobe Icons](https://github.com/lobehub/lobe-icons).
Brand names and marks remain the property of their respective owners. They are
shown only to identify the model family or upstream developer represented by a
LocalClaw catalogue record.

Files containing `-avatar` are public profile avatars returned by the
Hugging Face organization or user avatar API for the upstream handle recorded
in `scripts/fetch-home-index-avatars.js`, downloaded on 2026-08-14.

`tinyllama-avatar.jpg`, `ornith-avatar.png`, `smallthinker-avatar.png`,
`emotivoice-avatar.png`, `ai4bharat-avatar.jpg` and `kittenml-avatar.png` are
the public avatars of their official GitHub project owners. `rednote-avatar.png`
is the logo published by RedNote HiLab in its official Hugging Face Space.
