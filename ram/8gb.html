How to choose at 8GB

  • Use Q4_K_M or Q5_K_M quantization for the best quality/speed balance.
  • Leave memory headroom for macOS/Windows, browser tabs and LM Studio overhead.
  • For coding, prioritize catalogue coding and reasoning ratings. For chat, catalogue quality and speed matter more.
  • If a model feels slow, drop one size tier before changing hardware.

How this RAM-tier order works

This contextual order uses LocalClaw catalogue quality, reasoning, coding and speed fields plus freshness and RAM fit. It is not the homepage LocalClaw score, not a standardized third-party benchmark and never includes community stars. Catalogue summaries may repeat upstream claims; verify them at the linked model repository.
