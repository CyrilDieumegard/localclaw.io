Where should you start?

For a visual local chat app, start with LM Studio or Jan. For a command-line model runner and API, look at Ollama. For a document workspace, compare AnythingLLM and Open WebUI.

Need more control?

llama.cpp exposes inference controls directly. Colibri explores disk and memory streaming for large MoE models. Unsloth and MLX also support training workflows. Check each project's hardware notes before choosing.

For OpenClaw setup and ongoing management on a Mac, LocalClaw provides the control center around your chosen provider.

What the types mean

Desktop appA visual workspace for chatting with models and managing local files or settings.
Model serverRuns a model and exposes an API to other apps and agents.
Inference engineExecutes model calculations. Frameworks such as MLX provide the building blocks for these workloads.
Web interfaceA browser workspace connected to a model backend. The interface alone does not perform inference.
Complete stackA management layer around several components. LocalClaw operates OpenClaw while a separate provider handles inference.

How we compare

This is a curated directory, not a speed ranking or an exhaustive list. Each entry identifies its role, documented systems, main uses and setup limits. The Docs link points to an official source.

System filters include native installers, Docker or Python setups, and clearly labeled alternatives such as WSL or the community vLLM-Metal plugin. Support can differ by backend, GPU, model format and release.

To choose a model that fits your machine, use the AI Index and the RAM/GPU guide. This directory does not automatically read your saved machines.

Before you install

Does local software always keep data local?

Only when the models, embeddings and connected tools are configured locally. Apps that support cloud providers can send requests off your machine. Initial downloads also need an internet connection.

Does Colibri remove hardware limits?

No. Streaming experts from disk trades memory requirements for storage and latency. Supported models have different requirements; large checkpoints can need hundreds of gigabytes of disk space. Check the project's measurements and setup notes.

Is the software itself a model?

No. A model supplies the weights. An app, server or engine loads those weights or connects to the software that does.
