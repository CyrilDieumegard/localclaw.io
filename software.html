What software do you need to run local AI?

Quick answer: choose LM Studio when you want a visual desktop app, Ollama when you prefer a simple CLI and local API, Unsloth when you want a desktop workspace for running and training models, and llama.cpp when you want a lightweight inference engine with deep control. FreeToken, vLLM and SGLang target more specialized serving workloads. If your goal is to install and operate OpenClaw as a complete Mac stack, LocalClaw adds the management layer around the model provider.

There is no single best runtime

The best choice depends on your operating system, available RAM or VRAM, model format, preferred interface and whether other applications need an OpenAI-compatible endpoint.

How LocalClaw evaluates software

Entries require an official local installation path, identifiable platform support and a practical role in a local AI stack. Compatibility claims are checked against primary documentation from LM Studio, Ollama, Unsloth, llama.cpp, MLX and each listed project.

Common questions

Is LM Studio a runtime?

LM Studio is a desktop application that manages models and local servers. It uses runtimes including llama.cpp and MLX under the hood.

Can OpenClaw use a local model server?

Yes, when the server exposes a compatible endpoint and the selected model supports the required workflow. LocalClaw helps manage the surrounding OpenClaw installation and configuration.
