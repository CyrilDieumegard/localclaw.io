Three signals, never blended

Each signal answers a different question. No community average is converted into a software score.

01

Community ★ /5

Raw signed-in member average plus vote count. The confidence sort uses a transparent 3.5/5 prior over five votes; fewer than five votes is marked EARLY.

02

LocalClaw /10

Editorial catalogue rubric: 38% quality, 24% coding, 24% reasoning and 14% speed, using only maintained repository fields. It is not a standardized third-party benchmark.

03

Hardware fit

Compares installed RAM with the catalogue minimum. Context, runtime overhead, GPU offload and other applications can require more headroom.

Local model index FAQ

Short, source-aligned answers for people and answer engines.

What is The Local Model Index?

It is LocalClaw's hardware-aware directory of 218 unique local LLM pages and 56 local speech records. Hosted-only LLM records are excluded and duplicate route IDs are collapsed.

How is the LocalClaw score calculated?

The homepage LocalClaw catalogue score is a separate 0-10 method calculated from repository fields: 38% quality, 24% coding, 24% reasoning and 14% speed. It is not a community rating or an external benchmark leaderboard.

Are community stars mixed into the LocalClaw score?

No. Community stars are the independent 1-5 average from signed-in LocalClaw members, always shown with the number of votes. Community confidence uses only stars and vote count for ordering; EARLY means fewer than five votes. It never changes the LocalClaw score.

How should I choose a local model for 8, 16, 32 or 64 GB RAM?

Use the machine RAM selector or a RAM guide. A model is considered compatible when its catalogue minimum-RAM value is at or below the selected memory; context length, runtime overhead and other applications can require additional headroom.

Does the homepage include cloud-only or API-only models?

No. The homepage is a local-only index. Hosted-only LLM records, Edge TTS and OCTAVE 2 are excluded because the current catalogue does not provide a verified fully local runtime path for those records.

What speech models are covered?

The local speech index contains 56 records: 47 TTS models, 8 ASR models and 1 local speech application. Each entry keeps its Audio score separate from community stars.

How fresh is the LocalClaw catalogue?

This homepage snapshot was generated from the repository catalogue updated August 14, 2026. Release dates, RAM requirements, licences and links come from the maintained LocalClaw records and linked model pages.
