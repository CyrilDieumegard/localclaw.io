LocalClaw 1.0.176

OpenClaw Goals are now a clear product workflow. Pick a discussion, choose Local, OAuth, or Cloud, describe one durable objective, and let LocalClaw preserve it across work turns.

What changed

Guided Goals

A dedicated screen replaces slash-command guesswork with one objective editor and explicit Start, Continue, Pause, Complete, and Clear actions.

Any runtime

The same Goal workflow works with Local models through LM Studio, OpenAI OAuth models, and cloud models through OpenRouter.

Safer local choices

LocalClaw checks memory headroom, context size, model loading, and tool-use capability before starting. Weak models are blocked with a better recommendation.

Durable and efficient

Goal controls use OpenClaw's native session state without spending model tokens. Only Start and Continue send useful work to the selected model.

Existing customers

Open Updates in LocalClaw and install version 1.0.176. Your OpenClaw configuration, channels, chats, projects, local models, Cron Jobs, and Kanban tasks are preserved.
