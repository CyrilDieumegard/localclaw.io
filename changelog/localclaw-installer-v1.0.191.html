What changed

Current Node compatibility

Install and Updates now validate the supported Node 22, 24, 25, and 26 version floors used by current OpenClaw releases.

New OAuth models

GPT-5.6 and its Sol, Luna, and Terra variants are available as resilient fallback choices while the live OpenClaw model list remains the source of truth.

New local recommendations

Ornith 1.5, Ling 3.0 Tiny, and LFM 2.5 recommendations now cover agentic coding, compact reasoning, and local vision workloads.

Selection stability

Existing OAuth and local model choices are preserved during catalog refreshes instead of being silently replaced.
