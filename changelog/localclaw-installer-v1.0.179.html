What changed

One-click continuous Goals

Start a Goal once and LocalClaw automatically requests the next work step after each successful model response.

Honest live status

The Goals screen distinguishes Working now, Continuing automatically, and Waiting so an active objective is never confused with an active model request.

Clear safety stops

Continuous execution stops on completion, blocked state, usage or token limits, model errors, or an explicit Stop & Pause action.

Background continuity

A running Goal continues while you visit other LocalClaw sections. Switching to another discussion ends the previous continuous run cleanly.

Existing customers

Open Updates in LocalClaw and install version 1.0.179. Existing objectives and discussion messages are preserved.
