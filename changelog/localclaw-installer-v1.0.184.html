Local Goal reliability release

LocalClaw 1.0.184

Local Goals now keep compact models focused on the current step, retry one timeout automatically, and stop safely before an unproductive run consumes excessive tokens.

What changed

Bounded local context

LocalClaw trims the Goal transcript before every local turn and carries forward the verified checkpoint instead of repeatedly sending an ever-growing conversation.

Safe token limits

Local Goals receive an 80K token budget and each continuous run pauses after 60K tokens, keeping a weak model from running indefinitely without progress.

Automatic timeout recovery

The first local timeout triggers a compact retry from the saved workspace. A second timeout pauses the Goal and preserves every existing project file.

Smaller actionable plans

Single-file apps and games use two focused steps: create the complete deliverable, then verify the exact output on disk.

Existing local Goals

Install 1.0.184 from Updates, return to the Goal, and resume it. LocalClaw will reduce the active session context before the next turn. If the selected custom model still times out twice, choose the recommended local model or another runtime.
