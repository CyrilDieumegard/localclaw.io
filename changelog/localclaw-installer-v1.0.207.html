LocalClaw 1.0.207

LocalClaw can now install its future updates from inside the app. This release also improves OpenClaw 2026.9.2 recovery and fixes agent selection, model changes, Goals and automation status.

What changed

Update inside the app

In Updates, click Update under App update to download, verify, install and relaunch LocalClaw. Update all finishes dependencies and OpenClaw first, then replaces and relaunches LocalClaw last. Future releases no longer require dragging the app into Applications.

Reliable Gateway recovery

Maintenance checks the selected OpenClaw installation and its Node runtime. When OpenClaw says a restart is unsafe, LocalClaw keeps that restriction until recovery has been verified, including after relaunch.

The right agent and model

LocalClaw respects the selected agent’s model, authentication profile and workspace. A missing local model stays unavailable, and a failed model change no longer appears successful.

Goals and automation status

Goal operations use the selected runtime and workspace, with bounded waits. Automations whose completion was not observed show an unknown result after relaunch instead of an invented success or an automatic retry.

Clearer, safer diagnostics

Diagnostics redact credentials in nested JSON and HTTP headers. Gateway authentication errors lead to Gateway repair, and invalid CLI results no longer make an installation look ready.

OpenClaw 2026.9.2 validation

The real OpenClaw package was exercised in isolated fixtures covering configuration, agents, models, Goals, Doctor repair, Gateway transport, streaming and tool use. Provider responses were simulated; live provider accounts and external channels were not part of these checks.

Release verification

347 automated tests passed across 17 suites, followed by the isolated OpenClaw 2026.9.2 integration checks. The release app and DMG passed Developer ID signing, Apple notarization, stapling and Gatekeeper verification. A real click on App update → Update downloaded and installed this build, relaunched LocalClaw automatically and left the existing OpenClaw configuration unchanged.

Install this release once

If you are on LocalClaw 1.0.206 or earlier, its existing updater still opens the DMG. Replace LocalClaw in Applications one last time, then launch version 1.0.207. Future app updates install from Updates and relaunch automatically.

Automatic replacement needs write access to the Applications folder containing LocalClaw. If the shared folder is protected, install the app once in your personal ~/Applications folder. LocalClaw shows a clear instruction when it cannot replace the installed app.

Your saved license, OpenClaw configuration and workspaces stay in place. OpenClaw updates remain available from the same screen, with the existing recovery safeguards and any plugin capability review.
