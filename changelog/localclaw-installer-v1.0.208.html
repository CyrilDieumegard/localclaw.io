LocalClaw 1.0.208

Resource monitoring now excludes reclaimable cache from used RAM and explains what the whole-Mac and per-process numbers measure.

What changed

Corrected Mac RAM usage

Used memory is physical RAM minus free memory and reclaimable file and purgeable cache. This avoids treating useful cache as occupied application memory, while retaining system allocations. Available memory now includes reclaimable cache.

More reliable process detection

Home no longer formats integer memory counters as floating-point values, which could incorrectly display 0 MB. OpenClaw and Node processes no longer need an absolute executable path to be counted. OpenClaw entry scripts, including launches with Node memory options, and helper processes are recognized; LM Studio includes its helpers.

Clearer resource panels

Home and the resource panels explain that total RAM describes the whole Mac. Per-process groups show resident RAM (RSS), which differs from Activity Monitor’s Memory column. Groups can overlap and should not be added together.

Comparing with Activity Monitor

Compare the whole-Mac RAM gauge with Memory Used in Activity Monitor. Small differences can remain because each app samples at a different time. A high cache value alone does not mean your Mac is running out of memory; check memory pressure and swap too.

Release verification

354 automated tests passed across 18 suites, along with isolated OpenClaw 2026.9.2 integration checks. The final app was checked on a Mac Studio, including the running Gateway process and the Home resource counters. The app and DMG passed Developer ID signing, Apple notarization, stapling and Gatekeeper verification.

Update

On LocalClaw 1.0.207 or later, open Updates and click Update under App update. On 1.0.206 or earlier, download the DMG and replace LocalClaw in Applications. Your saved license, OpenClaw configuration and workspaces stay in place.
