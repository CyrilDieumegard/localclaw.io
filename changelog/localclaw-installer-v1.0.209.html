What changed

Routed Chat beta

A local decision model scores each prompt, then LocalClaw selects among the cloud models configured for this feature. The route card explains its choice and names the model actually used. Press Return to send a message.

Your decision stays on the Mac

The routing decision runs locally. Your message goes to the selected cloud provider when you send it, as it would in an ordinary cloud chat. Routed Chat is a separate experimental space; your direct model choices remain available.

Less repetitive maintenance

OpenClaw's 2.0 execution-approvals migration is limited to older runtimes that need it. Full state archives are reserved for known schema changes and recovery. Same-schema updates keep native safeguards without repeating the large archive.

Repair without unnecessary upgrades

Quick Repair checks your running Gateway first. A healthy installation keeps its current OpenClaw version. Ordinary configuration repairs use that installed version; an incompatible database schema can still require an upgrade.

Responsive maintenance commands

Large diagnostic output no longer depends on shared worker queues. Timed commands stop waiting at their deadline, including when a child process keeps the output pipe open. Unavailable update checks show their actual status.

OpenClaw 2026.9.6 compatibility

Goal actions now recognize OpenClaw's new module format. Skills listing and installation explicitly target the selected chat agent, including when the router adds a second agent. LocalClaw also verifies that a native updater targets the selected Gateway package before allowing it to proceed.

Beta scope

Routed Chat currently routes between configured cloud models. It does not load and unload local language models. An older OpenClaw installation with invalid configuration can require supervised package-manager recovery; LocalClaw stops if a temporary updater selects the wrong installation.

Release verification

The release gate checks the Swift suite, OpenClaw 2026.9.6 compatibility, legacy migration, native update repair and a real Gateway test turn in isolated state. The packaged app and DMG are checked for Developer ID signing, Apple notarization, stapling and Gatekeeper acceptance.

Update

On LocalClaw 1.0.207 or later, open Updates and click Update under App update. On 1.0.206 or earlier, download the DMG and replace LocalClaw in Applications. Your saved license, OpenClaw configuration and workspaces stay in place.
